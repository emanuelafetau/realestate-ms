## User Stories
 
---
 
### Real Estate Agent
 
As a real estate agent, I want to receive a notification when a new lead is assigned to me so that I can contact them before they reach out to another agency.
 
As a real estate agent, I want to see a full history of all my interactions with a client so that I don't have to ask them to repeat information they have already given me.
 
As a real estate agent, I want to log what a client is looking for — their budget, preferred location, and property type — so that I can match them to the right property without asking them again every time.
 
As a real estate agent, I want to search and filter properties by price, location, and size so that I can quickly find the best match for a specific client.
 
As a real estate agent, I want to add and update property listings from my phone or computer so that the information clients and colleagues see is always accurate and up to date.
 
As a real estate agent, I want to schedule property viewings inside the system so that I have everything in one place and never accidentally double-book myself.
 
As a real estate agent, I need to log what a client thought of a property right after a viewing so that I capture their honest reaction before I forget it.
 
As a real estate agent, I want to cancel or reschedule a viewing from the system so that the client is informed automatically without me having to contact them separately.
 
As a real estate agent, I want to log every offer a client makes and track its current status so that I always know where a deal stands without digging through emails.
 
As a real estate agent, I want to see the full negotiation history for a deal in one place so that I can refer back to any previous offer or counter offer at any time.
 
As a real estate agent, I want to upload and attach contracts to a deal record so that I never have to search through old email chains to find an important document.
 
As a real estate agent, I want the system to calculate my commission automatically when a deal closes so that I can trust the number is correct without doing the maths myself.
 
As a real estate agent, I want to see a breakdown of my commission earnings per deal so that I can track how much I have earned each month.

### Senior Real Estate Agent
 
As a senior real estate agent, I need to set a follow-up reminder on any client so that I never let a potential deal go cold because I forgot to call someone back.
 
As a senior real estate agent, I want to see all my clients organised by where they are in the buying process so that I know exactly who needs my attention today and who can wait.
 
As a senior real estate agent, I need to be alerted when a lead has had no interaction for too long so that no potential client is accidentally forgotten.
 
As a senior real estate agent, I need to be notified when a property I manage has been on the market too long without a sale so that I can speak to the owner and decide whether to adjust the price or strategy.
 
As a senior real estate agent, I want to upload photos and supporting documents to a property listing so that clients and colleagues have everything they need without having to ask me.
 
---
 
### Agency Manager
 
As an agency manager, I want to see all of my agents' performance on one screen so that I can immediately tell who is on track and who needs my attention before the month ends.
 
As an agency manager, I want to set a monthly sales target for each agent so that everyone on the team has a clear and personal goal to work toward.
 
As an agency manager, I need to approve deals before contracts are finalised so that I maintain oversight of all major transactions happening in the agency.
 
As an agency manager, I want to see which properties have been listed the longest without a sale so that I can reassign them or suggest a pricing change before the owner loses confidence.
 
As an agency manager, I want to reassign a lead or property from one agent to another so that workloads stay balanced and nothing is left unattended.
 
As an agency manager, I need to generate a monthly revenue report so that I can present accurate results to the agency owner without spending hours pulling data together manually.
 
---
 
### System Administrator
 
As a system administrator, I want to create user accounts and assign roles so that every team member has access to exactly what they need and nothing they should not see.
 
As a system administrator, I want a new agent to automatically receive a welcome email with their login details when their account is created so that they can get started without waiting for manual setup.
 
As a system administrator, I want to deactivate a user account when someone leaves the agency so that former employees can no longer access sensitive client and property data.
 
As a system administrator, I need to view a full log of every action taken in the system so that I can investigate any issue and know exactly who did what and when.
 
---
 
### Property Buyer
 
As a property buyer, I want to receive an automatic reminder before my viewing so that I don't forget the time or address and miss an appointment I was looking forward to.
 
As a property buyer, I want to receive property suggestions that match what I have told my agent I am looking for so that I don't waste time viewing properties that are not right for me.
 
As a property buyer, I need to be notified whenever the status of my offer changes so that I am never left anxious and wondering what is happening with the biggest purchase of my life.
